# Practical 7 - Java OOP Relationships

This repository contains the practical programs for **Practical 7** of Java Object-Oriented Programming.

## Topic

The programs demonstrate different types of relationships between classes in Java, including:

- Association
- Aggregation
- Composition

## Practical Questions

Currently, the following 5 questions have been implemented:

1. Car Engine System
2. Company Employee System
3. Order and OrderItem System
4. Student Management System
5. University Professor Management System

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- IntelliJ IDEA

## Concepts Covered

- Classes and Objects
- Association
- Aggregation
- Composition
- Object Relationships
- Constructors
- Methods
- Encapsulation
